## Run it

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` (1024x1024 JPEG bytes, 285,058 bytes) to
`/output/entry.png`. Standard library only, no network, deterministic — two
runs produce identical bytes.
